# 《就骰这亿把》微信小游戏提审收口清单

## 当前版本定位

- 游戏名：就骰这亿把
- 类型建议：休闲 / 益智 / 轻度闯关
- 核心玩法：玩家选择骰子凑出牌型，点击攻击挑战怪物，尽量在每日挑战中闯到更高关卡。
- 版本定位：短局挑战、轻策略、强反馈、好友榜。

## 提审简介

短简介：

```text
一款轻量骰子闯关小游戏。选择骰子组成牌型，打出伤害击败怪物，挑战今日最高关卡。
```

长简介：

```text
《就骰这亿把》是一款休闲骰子闯关小游戏。玩家每回合从桌面骰子中选择点数组成对子、顺子、三条等牌型，点击攻击后根据牌型计算伤害，击败当前怪物即可进入下一关。游戏包含每日挑战、好友排行榜和战绩分享，适合碎片时间游玩。
```

## 截图建议

至少准备 5 张竖版截图：

- 主界面：显示开始挑战、今日最好、排行榜入口。
- 战斗界面：显示骰子、怪物、血量、攻击按钮。
- 牌型反馈：显示对子/顺子等牌型艺术字和攻击数值。
- 失败界面：显示失败艺术字、再冲一次、好友助战。
- 排行榜界面：显示好友挑战榜。

截图注意：

- 不要出现“99%过不了”“必得奖励”“现金”“提现”“红包”等文字。
- 不要出现血腥、恐怖、骷髅过重、诅咒过重的表现。
- 不要把“本地估算数据”写成真实地区排名。
- 分享相关按钮可以出现，但不要写成强制分享或承诺分享必得。

## 已收口文案

当前已把以下高风险表达改成中性表达：

- “分享再来一次”改为“好友助战”。
- “求助好友可再战”改为“好友助战可继续”。
- 分享标题不再写“帮我解锁一次挑战”。
- 分享标题不再写“超过本地区 X% 玩家”。
- 排行榜页不再显示本地估算的“超过本地区 X% 玩家”。

## 仍需你后台准备

- 微信小游戏基本信息：名称、类目、简介、图标。
- 运营素材中的分享图地址，填入 `ConstValue.SHARE_CARD_IMAGE_URL`。
- 好友排行榜 key：当前代码使用 `rkstage`。
- 服务器域名和 OSS 域名：需要在微信后台配置合法域名。
- 隐私协议：如果后续保存 openid、昵称、头像，需要在隐私说明中写清楚用途。

## 当前功能合规说明

登录：

- 当前游戏内没有强制注册系统。
- 如后续接微信登录，后端只保存 openid、昵称、头像、分数、关卡等必要数据。

排行榜：

- 当前好友榜使用微信开放数据域。
- 主榜单字段是 `rkstage`，含义为今日最好关卡。

分享：

- 分享用于战绩展示和好友助战。
- 当前逻辑按调起分享后继续流程，微信侧无法稳定确认用户是否真实发送。
- 提审文案应避免写“必须分享”“分享必得”“解锁奖励”等强诱导表述。

广告：

- 当前代码里有激励视频和插屏广告入口。
- 提审前需要确认广告位 ID 已配置，且广告不遮挡核心玩法。

## 提审前自查

- 新用户首次进入能直接开始游戏。
- 老用户进入先到主界面。
- 每日挑战次数显示正确。
- 失败后“再冲一次”和“好友助战”流程正常。
- 今日次数用完后不会卡死。
- 好友榜在微信开发者工具中能显示。
- 远程 Bundle 加载失败时不会黑屏。
- 所有截图里没有高风险文案。
- 分享图和截图风格一致，不出现违规元素。
